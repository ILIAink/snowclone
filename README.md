## ServiceNow (SNow) Clone
This is a project that aims to re-create the experience of ticket handling in an ITSM environment using ServiceNow. 

### Goals
The project aims to improve upon ServiceNow in the following ways:
1. Optimizing Load Time
    - Currently, SNow suffers from very long load times when it comes to ticket creation, viewing, and updating. 

2. Better UI/UX
    - The UI of SNow looks very convoluted (in my opinion) and takes time getting used to. 

3. **Better AI Integration**
    - The main goal of this project is create better AI integration, where a company can opt for using existing documentation/knowledge-based articles (KBAs) to better assist engineers in resolving tickets.
